01 / Position

Not school software. School command.

Melo should be positioned as the operating layer for serious Nigerian private schools: academics, billing, report cards, parent visibility, and school prestige working together in one premium system.

Master name

Melo School OS. Keep it locked. Stop diluting it with SchoolOS, OS/SCHOOL, or generic “school management system” labels.

Core promise

Run your school with absolute clarity — less spreadsheet chaos, stronger parent trust, cleaner payments, and faster academic reporting.

03 / Direction

The route: Ivory Command.

Use one core system, not three competing identities. The design should feel like a private-school boardroom met a premium fintech dashboard.

Ivory Institution

Academic prestige, heritage, editorial spacing, gold rules, warm ivory canvas. Best for taste and proprietor ego.

Operational Trust

Dashboard proof, billing confidence, parent portal clarity, Paystack credibility. Best for sales and buyer anxiety.

Executive Noir

Sharp contrast, deep ink surfaces, restrained luxury. Use as spice, not the whole meal. Too much and it becomes fashion perfume.

04 / Logo Routes

A mark for leadership, not lunchboxes.

Avoid the usual graduation-cap swamp. The best mark is a premium monogram or institutional symbol that suggests structure, records, finance, academics, and parent trust coming together.

Woven Crest

Interwoven golden M: academics, finance, and community braided into one operating system. Most premium route.

Horizon Gate

Architectural M/gate mark. Suggests school prestige, institutional permanence, and moving into a cleaner future.

Editorial Pillar

Typography-first “Melo” wordmark with a subtle rising column. Strong for premium SaaS and print materials.

Kill list

No cartoon caps, primary-color books, happy children icons, pencils, globes, or “school app” clipart. We’re not doing PTA newsletter cosplay.

05 / First Asset

Build the parent-facing mockup first.

The first serious sales image should show a premium admin dashboard beside a mobile parent portal. It sells parent trust, fee clearance, and operational control faster than a logo ever will.

Hero composition

  • ✓iPad/laptop: admin command dashboard, broadsheet, report card, billing cards.
  • ✓Phone: parent portal with fee balance, result history, and Paystack payment state.
  • ✓Floating proof cards: “Payment cleared”, “Report card ready”, “Outstanding balance”.
  • ✓Warm ivory surface, black UI accents, gold lines, soft premium lighting.
Core line

Run your school with absolute clarity.

Melo School OS brings academics, billing, report cards, parent visibility, and school operations into one premium command center built for Nigerian schools.

06 / Flyer System

The WhatsApp flyer should feel like an executive invitation.

The flyer is not the place for every feature. It should sell the upgrade: less chaos, better fee collection, beautiful report cards, parent trust.

Academic Precision

Exam recording, broadsheets, grading, branded report cards, and term/session structure.

Financial Command

Fee plans, invoices, debt tracking, payment status, and Paystack-backed parent payments.

Parent Visibility

Mobile-first portal for results, billing, notifications, and the confidence parents expect.

07 / Rules

What we do. What we never do.

These rules keep the brand premium while avoiding the usual school software visual crimes.

Do

  • ✓Lead with product proof and clean dashboards.
  • ✓Use editorial typography, warm neutrals, and restrained gold.
  • ✓Talk like an operating system for school leadership.
  • ✓Show parent portal, report cards, billing, and term structure.

Never

  • ×No cartoon children, school buses, pencils, chalkboards, or generic caps.
  • ×No noisy rainbow gradients or kiddie primary colors.
  • ×No fake stats, security theater, or unverified uptime claims.
  • ×No long feature dumps that make it feel like database software from 2011.
