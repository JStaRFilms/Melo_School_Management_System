# Define capability-specific Sites interactions

## Objective
Keep the current Admin design while giving reviewers and publishers usable controls without editor permissions, explaining approval lifetime and automatic domain checks, and exposing a website icon default/override.

## Scope
The existing School site page and platform domain status copy. No new visual language, navigation-icon changes, payment/application flow or full review-preview redesign.

## Definition of done
The feature contract defines actual role flags, truthful source/lifetime choices, non-destructive persistent-domain status, explicit disruptive rotation, private Admin logo copy and published-only favicon behaviour.

## Expected artifacts
The authored interaction and data-flow sections in docs/features/ManagedSiteUpkeepAndBranding.md. Implementation follows this design rather than inventing new product scope.
