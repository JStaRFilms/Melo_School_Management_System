# OBHIS Website + Reusable Admissions Platform — Master Plan

Canonical plan: `docs/tasks/orchestrator-sessions/orch-20260722-114501/master_plan.md`

Deliver two coordinated capabilities in one monorepo and shared Convex backend: (1) a reusable tenant-aware paid admissions platform independent of website ownership, and (2) a bespoke OBHIS public website built on shared site infrastructure. Use a guardian-account-plus-paid-slots model, stage applicants until acceptance, permit structured admin content editing while keeping layouts code-controlled, and implement in isolated worktrees under an integration owner. Genesis freezes domain, security, content, route, and merge contracts; Design defines public/admin/site UX; Build proceeds through foundation, admissions, site-core, OBHIS, and integration tasks.
