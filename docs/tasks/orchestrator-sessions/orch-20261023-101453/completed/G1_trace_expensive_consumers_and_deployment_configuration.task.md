# Trace expensive consumers and deployment configuration

## Objective
Find evidence-backed waste in current archive/selectors, shared subscriptions, file delivery and scheduled work.

## Scope
Read repository guidance and current implementations. Verify safe deployment identity sources and telemetry availability without printing secrets or records. Independently trace frontend consumers. Do not edit implementation or call remote functions.

## Definition of done
Separate confirmed static costs from hypotheses. Distinguish internal reads, response bytes, subscriptions, files, backups and action fetches. Propose small fixes preserving complete results and authorization.

## Expected artifacts
Findings with source paths, consumer paths, existing indexes, test commands and measurement options.
