# Reduce evidenced client response waste

## Objective
Implement one narrow response-byte improvement selected from consumer tracing.

## Scope
Wait for Genesis findings and identify the exact function and consumer before editing. Prefer projection or view-scoped subscription using established authorization and existing indexes. Do not alter scores, balances, domain freshness or complete-list semantics. No shared-checkout writes while B1 runs.

## Definition of done
The selected consumer receives every field it needs, irrelevant heavy fields or inactive reads are removed, and focused tests demonstrate semantics and synthetic byte reduction. If no safe candidate exists, record why rather than speculate.

## Expected artifacts
Reviewed code change, focused tests and before/after evidence, or an explicit rejected-candidate finding.
