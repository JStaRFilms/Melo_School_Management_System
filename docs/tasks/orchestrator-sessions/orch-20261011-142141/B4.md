- Admin grants nonempty subset of requested named targets/fields using existing appropriate school-admin+capability checks.

- Exclude auth/email/password/admission IDs, class/session/subjects/results/fees/house assignments, household links/relationship/primary status/label/shared residential address, other contacts and uploads.

- Review normalized actual changed permitted fields. B1 name splitting may also change middleName; require scope for normalized induced changes rather than bypass field grant.

- Submit validates current allowed fields/ownership/baselines, applies through transaction-local safe B1 helpers, inserts or freezes immutable applied evidence and audit, consumes permission, in ONE mutation. No provider actions or asynchronous profile writes.
- Failed/stale/revoked submissions preserve data and never falsely claim successful apply. Identical concurrent/retried submission produces exactly one receipt/apply/audit; changed-content request-key reuse fails.
- Terminal requests never reopened. Admin grant/reject/revoke and post-submit audit, not a second approval queue.
- Names/auth/person/enrollment/promotions/subjects/fees/history remain consistent. No cross-school name writes.
