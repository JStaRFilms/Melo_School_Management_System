# B2 staff handoff

Implemented session-scoped class reporting choices at `/assessments/setup/reporting-modes`, linked from report-card bundles. The selector uses active class rows and server lock state; subject setup links to `/academic/subjects`. Choices do not create subjects or alter enrollment.

Teacher `/assessments/exams/entry` and admin `/assessments/results/entry` query class mode before graded score sheet and render per-subject roster comments for narrative classes. Graded score entry remains the existing path. `narrativeEntrySheet:getSheet` bounds class roster and draft reads, applies session enrollment, student subject selection and teacher subject authorization; `saveDraft` is the write guard. Drafts are labeled private, issued comments are read-only. Teacher report-card workbench avoids the graded card and extras queries in narrative mode and links to normal subject entry. Admin `/assessments/report-cards` with student/session/term/class IDs uses `getStaffPreview` to show all subject comments, missing comments and single-student review/publish; graded preview/certification stays intact. Narrative print is single-student, with draft watermark; graded batch printing remains unchanged. Admin launcher must supply a class ID for mode dispatch.
