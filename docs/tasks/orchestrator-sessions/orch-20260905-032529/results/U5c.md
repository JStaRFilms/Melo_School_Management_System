## Storage / policy contract

Finalized quarantine and Archive count as active bytes. Trash transfers active to trash without reducing consumed; rollback/candidates remain temporary. Remaining = allocated − consumed − reserved, clamped at zero. Unknown legacy bucket values are null/not recorded, never invented zeros. Explicitly disclose knowledge-library and abandoned-upload reconciliation gaps.

`assetPolicies` supplies validated per-school max bytes (1..100 MB technical safety ceiling), Trash days (1..3650), and a bounded approved-policy reference via **internal-only** `configurePolicy`. Default is 25 MB / 30 days when absent. UI explicitly says technical default, not a purchased plan entitlement. U5b does not have an authoritative versioned purchased allowance/cap lifecycle; this packet does not invent one or infer entitlement from invoice/catalog. Policy changes affect subsequent Trash deadlines, not existing holds/deadlines.
