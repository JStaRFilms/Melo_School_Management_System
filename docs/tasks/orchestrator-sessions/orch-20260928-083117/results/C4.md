# C4 selector scale correction

Admin release context now reads only school authority and pause control. Four indexed, 24-at-a-time selector lists cover sessions, terms within a validated school session, classes, and published tuples. Each list has a Load more control. Published tuples can be found after the first page even when the class, session or term is archived. An exact tuple lookup hydrates selected options outside the current page and rejects mismatched or foreign IDs. Unpublished inactive periods show the historical-reconciliation blocker rather than a release form. The existing frozen-release panel, pause control and server permission checks remain in place.

Backend tests create 257 archived publications and more than 256 classes, sessions and terms. They cover paging, archived inspection, an active eligible release, wrong-school lookup, foreign session rejection and unauthenticated selector denial. UI tests cover a 257-item published list, archived inspection, active pause, invalid deep links and inactive-period messaging.
