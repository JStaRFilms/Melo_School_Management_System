# PR #88 P1 branch-context correction

Addressed Codex inline 4126960509 against reviewed head 19b03b3. All public `resultPublication.ts` queries and mutations now accept a selected `schoolId`, resolve active membership for that exact branch, and apply the existing branch capability or admin check before looking up selectors, readiness, exclusions, pauses, or publications. Existing callers may omit `schoolId` and retain their authorized legacy-school behavior; that fallback is not used by the Admin release workspace. Tuple and school consistency checks remain in place.

The Admin page takes the branch from `workspaceAccess.branch.schoolId`, waits until a branch exists, and passes it into context, paginated selectors, selection, readiness, pause, exclusion, and release calls. A branch switch remounts the page content and clears its tuple, review dialog, pending flags and pause state, including when workspace access briefly enters loading. A URL tuple is used only on the initial branch visit. Context must return the requested school before the panel or selectors render.

Added a Convex multi-branch test: a user with membership in a selected non-default branch can read its selectors, pause it as admin, exclude a student, and release it as officer. A foreign branch is denied, and a branch with explicit capability restrictions is denied. Admin component tests verify non-default branch arguments, no query before selection, pause mutation arguments, and tuple reset across a loading-state branch switch.
