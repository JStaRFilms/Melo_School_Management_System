# PR #88 selected-result availability

Codex P2 inline 4138936887 was valid. A student excluded from a released class, or admitted after its roster froze, previously got `withheld`, the same state used when a school had not released results at all.

`getWorkspaceData` now returns the existing score-free `no_eligible_record` state only when server-side evidence identifies an exact school, session, term and released class for the selected student. An approved exclusion uses a new student-keyed index on `classResultExclusions`, requires a matching released tuple and an approval no later than release. A late student needs an active student/class/session/term, a student row created after that exact class release, and no frozen inclusion. Both paths reject conflicting inclusion, exclusion or issued-class evidence. Unreleased terms and uncertain historical membership stay `withheld`. These checks return only a state. They never return an exclusion reason, assessment data or a release identifier. The existing issued-card lookup and bounded student history are unchanged, as is the optional `now` argument for cached Portal clients.

Tests cover an excluded student before and after release, class change after exclusion, conflicting same-term exclusions, late admission even with more than 32 other released classes, older students missing an inclusion, an unrelated unreleased term, and score/reason-free payloads. Existing Portal UI tests already check the `no_eligible_record` copy and absence of a printable sheet; no copy or UI code changed.

Verification passed: Convex typecheck and all 659 tests in 88 files; Portal typecheck and all 8 tests in 2 files; targeted backend ESLint and `git diff --check`. The informational theme audit reported existing product-neutral fallback colours in `portal.ts`. Direct colours in concurrent Admin changes were outside this task. No colour changes were made.

Historical class without a frozen exclusion remains `withheld`; current-class identity alone does not prove enrollment in an old term. FR-023 narrative integration remains separate.
