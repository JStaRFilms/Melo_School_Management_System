# B3 Admin release controls

Added `/assessments/report-cards/release` beside the Admin report-card launcher. The new view reads bounded session, term and class options plus role flags from `resultPublication:getReleaseContext`. This small backend query was necessary because the existing Admin selectors reject exam officers, who are allowed to release by the B1 policy. Readiness and both writes still enforce their own server-side capability, tenant and school-admin checks. The screen shows roster blockers without marks, frozen counts and original release metadata. An admin can enter one reasoned exclusion at a time. A publish-final holder can confirm the exact B1 sentence and submit the current review key. Changed selections remount the panel and discard dialogs, typed reasons and confirmation. A changed review key disables confirmation; a stale mutation response clears the checkbox and holds the old key until the reactive readiness query returns a different review. The certification copy now makes the separate class release explicit. Staff previews are not described as published.
