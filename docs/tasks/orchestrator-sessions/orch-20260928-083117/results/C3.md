# C3 Admin pause UI correction

The release page now shows the school's pause state, latest reason and update time. School admins can pause or resume new class releases with a specific reason and an explicit confirmation. Exam officers see the status without a toggle. A pending pause blocks the UI immediately; while paused, the release action stays disabled, but already released tuples still show their original frozen release details. The server still enforces permission and pause state for direct calls.

Readiness actions now use the server's `canExclude` and `reasonCode`, not the displayed reason text. The reason remains visible to staff. Added UI tests for pause and resume, failure with retained reason, exam officer visibility, frozen release status, and stable exclusion permissions.
