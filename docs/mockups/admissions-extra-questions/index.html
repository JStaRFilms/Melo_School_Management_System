Meridian Crest Academy · Admin → Admissions. Each file is standalone, open it in a browser. Pick one direction, or mix them.

V1 · RecommendedFocused cardsGoogle-Forms-style done right. Numbered cards, left drag rail, icon-only row actions, choices inline. Fixes the giant Duplicate / Remove buttons. What’s wrong in the current screenshot:
  • Duplicate + Remove are full-width primary-sized buttons — they visually outweigh the question itself.
  • Up/down arrows are orphaned, tiny, no drag affordance, no question numbers.
  • “Question / Answer type / Required” labels repeat identically on every card — noisy.
  • Choices (“Option 1yes”, “Option ss”, “hehe”) have no validation state and the × buttons look like text inputs.
  • Sticky “Saving… / Cancel” bar overlaps the next card. No progress (“2 of 5”) or parent preview.
